## What it is

`polymarket-mcp` is a TypeScript MCP server that exposes Polymarket capabilities over **stdio** for AI agents and MCP clients.

It combines:

- public market discovery and pricing tools
- authenticated account and trading tools
- relayer and builder-relayer execution flows
- bridge and tx-builder utilities
- websocket burst capture for live data snapshots
- reusable prompts and resources for structured agent workflows

## Major capabilities

- **Public discovery:** list/search markets and events, fetch order books, prices, spreads, and trade history.
- **Authenticated trading/account:** API key management, balances/allowances, order creation/post/cancel, rewards and notifications.
- **Relayer + builder-relayer:** nonce/payload inspection, transaction execution/deploy, and poll-until-state helpers.
- **Bridge + transaction builders:** supported assets, deposit/status checks, and EVM transaction payload generation for CTF/neg-risk flows.
- **Websocket bursts:** bounded collection from market, user, and sports websocket endpoints.
- **Prompts + resources:** agent-ready prompts (`market-analysis`, `portfolio-review`, `execution-checklist`) and JSON resources (`polymarket://status`, etc.).

## Safety model and secret handling

<Warning>
  Keep all credentials in environment variables or a secrets manager. Never paste secrets into prompts or commit them to source control.
</Warning>

The server is designed for agent safety:

- **Mutation guard:** state-changing tools require `confirm: true`.
- **HTTP guardrail:** `generic_http_request` only allows approved Polymarket hosts, requires explicit `method`/`path`, blocks auth-sensitive headers, and bounds response size.
- **Redacted runtime status:** resource `polymarket://status` reports readiness without exposing secret values.
- **Graceful auth behavior:** some authenticated flows return structured skip diagnostics when required auth vars are absent.
