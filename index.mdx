## What is Carbon Copy?

Carbon Copy is a copy-trading platform built on top of [Polymarket](https://polymarket.com) — the world's largest prediction market exchange. The Carbon Copy API gives you direct, programmatic control over everything you can do on the platform:

- **Follow traders** — choose which wallets to mirror and how aggressively
- **Manage positions** — view your open copy trades and P&L in real time
- **Audit orders** — inspect every order your bot has placed
- **Automate strategy** — pause, resume, and tune copy settings without touching the UI

## Key concepts

<CardGroup cols={2}>
  <Card title="Copy trading" icon="copy">
    When a followed trader places a bet on Polymarket, Carbon Copy automatically replicates it in your account at a configurable percentage and max size.
  </Card>
  <Card title="Scoped API keys" icon="key">
    Every API key carries a set of scopes (`portfolio:read`, `traders:write`, etc.). Issue narrow keys for your bots and never over-privilege them.
  </Card>
  <Card title="Cursor pagination" icon="arrow-right">
    All list endpoints use opaque cursor-based pagination — no page numbers, no offset drift. Stable even if new records arrive mid-iteration.
  </Card>
  <Card title="Rate limits" icon="gauge-high">
    Read endpoints allow 60 req/min with a +10 burst. Write endpoints allow 20 req/min. All limits are per API key.
  </Card>
</CardGroup>
